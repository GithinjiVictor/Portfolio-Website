Problem
Smallholder farmers in Kenya make market-selection decisions based on guesswork, leaving significant revenue on the table by selling at the wrong markets at the wrong time.
Approach
A full-stack decision support system combining multi-model price forecasting (EMA, SMA, Linear Regression), a profit engine, voice NLP assistant (SautiSoko), and strategy backtesting — all built with React + Django REST Framework.
React.js Django REST Python Recharts SQLite Web Speech API JWT Auth Tailwind CSS
Key Features
EMA · SMA · Linear Regression Forecasting Net Profit Engine (Price × Qty − Costs) 13 Regional Kenyan Markets SautiSoko Voice Assistant (NLP) Strategy Backtesting vs Human Baseline Excel / PDF Report Export JWT Authentication Bulk Data Import / Export
Empowers Kenyan smallholder farmers to compare prices across 13 markets, calculate real net profit after transport costs, and receive AI-optimised market recommendations — quantifying revenue uplift over the traditional nearest-market strategy.
